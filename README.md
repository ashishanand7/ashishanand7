## Selected work

### [inspect-rca-eval](https://github.com/ashishanand7/inspect-rca-eval) · Agent evaluation

Evaluation harness for telemetry-grounded root-cause analysis, built with Inspect AI and OpenRCA. Bounded read-only tools, deterministic scoring and reproducible runs.

A published study of **250 trajectories across five models and ten OpenRCA Bank incidents**, covering evidence selection, failure modes and repeat stability.

[Technical brief](https://ashishanand7.github.io/inspect-rca-eval/technical-brief.html) · [Findings and limitations](https://github.com/ashishanand7/inspect-rca-eval/blob/main/reports/frozen-bank-v4-3-findings.md)

### [EvidenceDesk](https://github.com/ashishanand7/EvidenceDesk) · Evidence verification

A synthetic-data prototype for evidence verification, with exact citations, numerical checks, abstention and inspectable traces. A deterministic verifier is tested against a 19-case adversarial suite.

[Architecture and walkthrough](https://github.com/ashishanand7/EvidenceDesk#architecture) · [Evaluation](https://github.com/ashishanand7/EvidenceDesk/blob/master/artifacts/evaluation.md)

### [chat-with-docs](https://github.com/ashishanand7/chat-with-docs) · Earlier RAG work

Local document Q&A using LangChain, Chroma and local LLM inference, with retrieved sources shown alongside answers.
